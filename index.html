Fase 1: Pengenalan Konsep VPS & Cloud

Pertanyaan / Instruksi: Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.

Shared Hosting

Berbagi Resource

Layanan hosting di mana satu server fisik dipakai bersama oleh banyak pengguna sekaligus. Seluruh pengguna berbagi sumber daya (CPU, RAM, dan penyimpanan) yang sama. Biaya sewanya paling terjangkau dan pengelolaannya mudah (umumnya menggunakan cPanel), namun performanya terbatas, tidak memiliki akses root, dan rentan melambat jika ada pengguna lain yang mengalami lonjakan trafik.

Cocok untuk: Website portofolio, blog pribadi, atau web profil skala kecil.

Dedicated Server

1 Server Fisik Penuh

Layanan penyewaan satu unit server fisik secara utuh dan eksklusif untuk satu pengguna/organisasi tanpa dibagi dengan pihak lain. Pengguna memegang kendali penuh (akses root/administrator) atas perangkat keras, sistem operasi, serta keamanan. Menawarkan performa dan stabilitas tertinggi, namun biayanya paling mahal dan membutuhkan keahlian teknis manajemen server.

Cocok untuk: Sistem enterprise, game server besar, atau aplikasi trafik sangat tinggi.

Amazon Lightsail

Simple Cloud VPS

Layanan Virtual Private Server (VPS) dari AWS yang dirancang praktis dan ramah pemula. Lightsail menggabungkan komputasi (VM), penyimpanan SSD, dan kuota transfer data ke dalam satu paket harga bulanan yang tetap (fixed price). Dilengkapi antarmuka yang sederhana serta blueprint instan (seperti WordPress, Node.js, atau LAMP) untuk mempercepat proses deployment.

Cocok untuk: Proyek skala kecil-menengah, staging/testing, dan aplikasi web standar.

Amazon EC2

Scalable Cloud IaaS

Layanan komputasi cloud (Elastic Compute Cloud) tingkat lanjut dari AWS yang sangat fleksibel dan dapat diskalakan (scalable). Menggunakan skema biaya sesuai pemakaian (pay-as-you-go) dan mendukung kustomisasi mendalam pada jaringan (VPC), keamanan (Security Group), pilihan spesifikasi ribuan tipe instance, hingga fitur Auto Scaling dan Load Balancing.

Cocok untuk: Aplikasi produksi skala besar, SaaS, microservices, dan arsitektur kompleks.
